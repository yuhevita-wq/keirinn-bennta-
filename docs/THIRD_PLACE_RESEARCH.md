# F1・S級 3着の発生位置と条件付き確率：結果起点の数学研究

2026-10-18｜**14,081レース、3着候補69,300件**。1着モデル・2着モデルは変更しない。

## 1. 研究手順

固定済みのF1・S級出走表、予想ライン、1着独立勝率 `q_k` と**実際の1・2・3着**を照合する。まず結果から第三入線者の位置を集計し、ハーヴィル条件付き3着確率 `q_k/(1-q_i-q_j)` の予測と対照。その残差からラインの所属・相対位置・ライン役割を分け、係数を最尤推定した。

対象：2024年〜2026年9月、5車148R、6車809R、7車13,124R。A級・G級・ガールズは含めない。母数を恣意的に絞らない。

## 2. 実際の3着はどこにいたか

1・2着が**同ライン**のレース：7,694R。

| 3着の所属 | 実際の回数 | 構成比 |
|---|---:|---:|
| 1・2着と同ライン | **2,539** | **33.0%** |
| 他ライン | 5,155 | 67.0% |

1・2着が**異ライン**のレース：6,387R。

| 3着の所属 | 実際の回数 | 構成比 |
|---|---:|---:|
| 1着のライン | **2,257** | **35.3%** |
| 2着のライン | **1,999** | **31.3%** |
| どちらとも違うライン | **2,131** | **33.4%** |

実測とハーヴィル基準との最も大きな差は、1・2着と**同一ラインで2人の後ろ**にいた候補：3着実績1,895件に対し期待値約411件。1・2着と同ラインの3着全体では実績2,539件・基準期待値約911件。これは独立勝率からの単純な正規化では表現できない。

## 3. 第三着の条件付き確率の数式

実際の1着を `i`、2着を `j`、3着候補を `k` とし、採用済みの**独立1着勝率**を `q_k` とする。

\[
P(k\mid i,j)=\frac{q_k^{\delta}\exp[D(i,j,k)+R(k)]}
{\sum_{h\notin\{i,j\}}q_h^{\delta}\exp[D(i,j,h)+R(h)]}
\]

**全14,081レースを使った最尤推定（研究基準）**：

\[\boxed{\delta=0.4891292239397931}\]

ライン内前後位置の `D(i,j,k)` は次のいずれか一つを採用する。基準「1・2着の両ライン以外」では `D=0`。

| 3着候補の位置 | 係数D | exp(D)の概数 |
|---|---:|---:|
| 1・2着と同ライン・2人より前 | +1.09065 | 2.98倍 |
| 1・2着と同ライン・2人の間 | +0.95213 | 2.59倍 |
| **1・2着と同ライン・2人より後ろ** | **+1.52609** | **4.60倍** |
| 1着ラインのみ・1着より前 | +0.69884 | 2.01倍 |
| 1着ラインのみ・1着の直後 | +0.83554 | 2.31倍 |
| 1着ラインのみ・さらに後ろ | +0.04354 | 1.04倍 |
| 2着ラインのみ・2着より前 | +0.48417 | 1.62倍 |
| 2着ラインのみ・2着の直後 | +0.82088 | 2.27倍 |
| 2着ラインのみ・さらに後ろ | +0.07011 | 1.07倍 |

さらに選手の**ライン内役割**を `R(k)` として加算する（先頭が基準0）：番手 +0.17889、3番手以降 +0.42244、単騎 +0.52720。

各 `exp(D)` は、他条件の同じ候補と比較した**正規化前の相対重み**。これをそのまま3着確率に掛けることはできない。役割係数も分母に含めて正規化する。

## 4. 同じ条件での数式比較

学習側6,393Rで各候補式を推定し、2025年4月以降の7,688Rで比較した**条件付き3着対数損失**（小さいほど良い）。条件は実際の1・2着を知った上で3着を予測する問題。レース前の3連単全体の的中率ではない。

| 数式 | 7,688Rの対数損失 | 条件付き3着1位候補の的中率 |
|---|---:|---:|
| ハーヴィル基準 | 1.686341 | 30.46% |
| ベンター香港競馬の指数δ=0.65 | 1.584027 | 30.46% |
| F1・S級からδのみ推定 | 1.550806 | 30.46% |
| δ＋1・2着ライン所属 | 1.448182 | 39.40% |
| δ＋厳密な前後位置 | 1.436614 | 39.30% |
| **δ＋前後位置＋候補選手の役割** | **1.430903** | **40.23%** |

後期間539日を単位として再標本化した改善の95%区間：

- ライン所属を指数単独に追加：対数損失 **0.10262改善**、95%区間 `[0.09238, 0.11275]`。
- 厳密な位置をライン所属の代わりに導入：**0.01157改善**、95%区間 `[0.00828, 0.01487]`。
- ライン役割を位置に追加：**0.00571改善**、95%区間 `[0.00277, 0.00893]`。

このため、**3着では位置＋役割の13係数（指数δ＋位置9＋役割3）を研究基準モデルとして採用**する。発見後の係数は全14,081Rで再推定し、[third_conditional_v1.json](../models/third_conditional_v1.json) に固定した。

## 5. レース前は全順序確率へ展開する

実結果を条件にした式を、そのまま未知のレースへ当てはめることはできない。採用済みの1着と2着式も組み合わせて、すべての異なる `(i,j,k)` について

\[
\boxed{P(i,j,k)=q_i\;P(j\mid i)\;P(k\mid i,j)}
\]

を計算する。これによって7車では**210通り**の3連単順序確率と各車の1・2・3着周辺確率が求まる。計算コードは [`src/predict_ordered_triples.py`](../src/predict_ordered_triples.py)。事前の出走表と予想ラインのみを渡し、確定1・2・3着を予測入力に含めない。

## 6. 留保

- 過去のレース出走表・ラインの取得時点は、締切15分前の原始スナップショットとして認証されていない。
- 全14,081Rで再推定した係数の当該母数での損失は**標本内**。時系列後期間も、過去の別研究で一部が見られているため完全初見ではない。
- 3着モデルの条件付き成績は、事前3連単の利益、的中率、券種オッズとの優位性を示していない。
- 市場オッズとの統合、車券期待値、ベット配分は未実施。2着や1着の採用済み係数は変更していない。
