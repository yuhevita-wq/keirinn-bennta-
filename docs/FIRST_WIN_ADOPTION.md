# F1・S級：1着独立勝率モデルの正式採用（2026-10-18）

**結論：特殊区分 `term=999` を正しく扱うV2系モデル＋高確率域校正を、次段階のF1・S級2着・3着研究用1着確率として採用する。**

これはユーザーの「ベンターと同程度の数値なら採用」の基準に基づく。F1・S級以外へ適用しない。旧V7の研究履歴と係数は消さない。

## 論文と同一定義の指標

ベンター（1994）p.189 式(3)：
`R²=1 - L(model)/L(1/N_j)`。

| 指標 | ベンター原論文 | 現行F1・S級（修正版1着） |
|---|---:|---:|
| 独立勝率モデルの擬似R² | **0.1245** | **0.18701814902834113** |
| 公衆オッズ統合モデルの擬似R² | **0.1396** | **未実施** |
| 対数損失 | ― | **1.571834380588097** |
| Brierスコア | ― | **0.7353548968114283** |
| 1着候補1位の的中率 | ― | **0.3864464099895942** |
| 1着候補上位2位以内 | ― | 約 **0.62955** |
| 校正・2着3着研究に利用できる1〜3着一意の予測済みレース | ― | **14,081R** |
| 時系列評価のレース | ― | **7,688R（53,208選手候補）** |

ここでいうR²は**同じ数式による数値比較**である。競馬・競輪では勝ちやすさと出走規模が異なり、「ベンター以上の予測力」の証明ではない。ベンターの市場統合効果（公衆オッズを上回る追加情報量）は未計測。

## 採用する予測確率

- 対象F1・S級のみ、全国・全予想ライン・5〜9車（実際の有効車数）を含める。
- モデルは **V2 `full_plus_line` 多項ロジット**。確率推定にオッズは使用しない。
- 既存の `term=999` は外国人選手の特別区分であり、通常の養成所期数として連続的に標準化しない。999を数値の期数から除外し、独立0/1カテゴリを**希少性で標準化せず**正則化付きで推定する。外国人選手もレースも除外しない。
- 同じ12予測期間それぞれで**それ以前の結果だけ**を学習に使用し、出力・モデル係数・ハッシュを別CSV/JSONに固定：
  `research/benter_walkforward_v7/frozen_term_unscaled/independent_win_*.csv` と `manifest_*.json`。
- 1着元勝率を `p_i` として高確率域校正係数は開発期間6,393Rから **`θ=0.6412587661746468`**。
  `s_i=log(p_i)-θ max(p_i-0.4, 0)`、
  `q_i=exp(s_i)/Σ_j exp(s_j)`。
  式は各レースで正規化し、確率総和を1とする。
- 評価対象2025年4月〜2026年9月には、評価期間の結果で再学習せずにこの校正を適用した。2024年〜2025年3月は研究用の校正係数推定期間であり、その確率は開発標本内である。

## モデル採用の比較

同一7,688R・同じ確定勝者で、旧 `term=999` 連続数値処理＋高確率校正との比較：

| 指標 | 旧1着 | **今回採用** |
|---|---:|---:|
| R² | 0.1828376 | **0.1870181** |
| 対数損失 | 1.5799172 | **1.5718344** |
| Brier | 0.7364081 | **0.7353549** |
| 1着確率1位の的中 | 38.619% | **38.645%** |

対数損失の平均改善 `+0.00808`。日単位クラスターブートストラップ95%区間 `-0.00109〜+0.01915` なので、新旧差の統計的優位はまだ確定しない。ただし、外国人の999を連続した期数として扱っていた入力設計上の誤りを修正できているので、**新しい数式体系で研究する基準版**として採用する。

高勝率帯80%以上では旧版・期待53.2勝対実現40勝から、修正版・期待19.8勝対実現19勝に校正残差が改善した（候補の構成は修正で変化するため単純な同一候補比較ではない）。

## 検証および後続工程の制約

1. 完全リアルタイム取得の原始スナップショットとは異なる歴史的レース別出走表を使用している。
2. 2026年7〜8月の旧モデル残差を見て999の誤処理を発見・修正した。したがって7,688Rの新旧改善は**純粋な完全未使用データによる優劣証明ではない**。
3. この採用は「F1・S級の次の2着・3着確率研究に使用する1着の基準」についてのみ。オッズ市場との差、券種の優位、払戻・期待値プラスまで認定したものではない。
4. **旧V7に保存した2着・3着の `γ,δ,a,b` は、異なる元勝率に対する旧標本の係数であり、新しい `q_i` とそのまま組み合わせて完成モデルとはしない**。次工程では同一F1・S級14,081Rの結果から改めて導出する。
5. 既存V7のコード・凍結パラメータは過去研究として無変更で保持。元モデルも別ディレクトリに保存してあり再比較可能。
