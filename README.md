# 競輪ベンター研究｜F1・S級専用

**研究本体。旧リポジトリは原始データの保管庫。**

このリポジトリは、F1・S級の実結果と出走情報から、ビル・ベンター方式で**1着 → 2着 → 3着 → 全券種の市場価格誤差**を順に研究するためのものです。

## 現在地（2026-10-18）

| 工程 | 状態 |
|---|---|
| **F1・S級の母数固定** | 14,081R（1〜3着一意・凍結予測あり） |
| **1着独立勝率** | 研究基準モデルとして採用 |
| 2着条件付き確率 | 研究前。旧V7係数を転用しない |
| 3着条件付き確率 | 研究前。旧V7係数を転用しない |
| 全券種の市場統合・期待値判定 | 未実施 |

採用済み1着独立モデル：**V2 `full_plus_line` 多項ロジット＋`term=999` の非標準化0/1カテゴリ＋高確率域校正**。

2025-04以降7,688Rでの評価：

- ベンター式擬似R²：**0.1870181490**（ベンター1994年論文の独立勝率モデルは0.1245）
- 対数損失：**1.5718343806**
- 1着確率1位の的中率：**38.64%**
- **競馬と競輪では出走数・難易度が違い、擬似R²の大小だけで両モデルの優劣は判断できない。**
- 市場との統合や収益率を検証した数字ではない。

## 研究上の原則

1. **対象はF1・S級のみ**。F2/A級/G級/ガールズをこのモデルに混ぜない。
2. 結果から法則を発見するために、14,081Rを研究対象として使える。未使用サンプル確保を口実に発見対象を狭めない。
3. レースの事前予測には、そのレースの結果や以後の結果を入力しない。法則の発見と未来予測の評価を区別する。
4. 事前に券種・車番・点数・買い方を固定しない。全券種と市場の実オッズを比較し、実測で優位のある価格だけを調べる。
5. 旧V7の2着・3着係数は**新しい1着勝率に接続しない**。新しいF1・S級母数で改めて推定する。

## データの保管場所

原始データ・歴史的な四半期ごとの独立勝率CSVは、容量の重複を避けるため既存の
[`keirin-market-analysis-`](https://github.com/yuhevita-wq/keirin-market-analysis-)
に保持する。**元の採用時コミットを `data/source_ledger.json` に固定する**ので、その後に旧ブランチが更新されても参照対象は変わらない。

**重要な留保**：歴史的出走表は後日取得した記録であり、当時の締切15分前と完全一致する事前スナップショットであることは未確認。本番前15分の確率・オッズに対する収益性は未検証。

> このリポジトリは研究成果の保管と再現のためのもので、車券の期待収益を保証するものではありません。
